## What the KIV-2 figure shows, and does not

`pangenome/hprc_kiv2_gbz_walks` loads the static cut through `gfaLocation` in
Sample rows. The layout places each off-reference node once, in the row of the
first walk that visits it (`pathAnchoring.ts`, `anchorNode`), and keeps the
full visitor list only as the node's `samples`. So the rows are attribution by
first visit among the eight, not carriage. The caption says so. The display
analysis argues carriage belongs in a genotype-matrix surface rather than a
rebuilt renderer; the vision doc and GBZ_PLAN Phase 7 record the same.
